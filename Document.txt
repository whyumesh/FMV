📘 1. Overview

The FMV Calculator Automation System is designed to streamline and automate the process of matching DVL (Doctor Validation List) entries with CV survey data, applying a standardized scoring mechanism, and updating the FMV Calculator accordingly.

This automation eliminates manual matching, data cleaning, and tier calculation, ensuring accuracy, consistency, and time efficiency for large-scale datasets (typically ~25,000+ records).

⚙️ 2. Objective

Automatically match and merge data between multiple source files:

FMV_Calculator_Updated.xlsx

CVdump.csv

DVL.csv


Apply standardized scoring and tier logic to each HCP (Healthcare Professional) based on survey data.

Generate updated and validated outputs:

FMV_Calculator_Updated.xlsx (updated master)

Missing_Doctors.csv (HCPs without survey data)

DVL_updated.xlsx (final export for business use)

🧠 4. System Workflow

The automation follows a modular pipeline of 6 major stages:

Stage 1: Data Loading

Reads input files (FMV, CVdump, DVL) safely using multiple encoding and parsing methods.

Validates each dataset for completeness and required columns.

Automatically adjusts header rows for FMV files with non-standard formats.


Stage 2: Data Cleaning & Processing

Normalizes all email IDs (trims, lowercases, removes noise).

Parses “Start time” in multiple date formats using custom parsing logic.

Handles duplicates in CVdump — retains only the latest survey per email.


Stage 3: Matching Logic

Matches DVL entries to CVdump data using HCP Email.

Creates two outputs:

Matched records → merged and prepared for scoring.

Missing records → exported to Missing_Doctors.csv.



Stage 4: FMV Calculator Update

Updates existing FMV entries where email matches.

Adds new doctor entries automatically if not present.

Creates a backup of the FMV file before modifications.


Stage 5: Scoring & Tier Assignment

Loads scoring rules from scoring_criteria.xlsx.

Calculates 9 individual scores per doctor based on:

1. Years of Experience


2. Clinical Experience


3. Leadership Roles


4. Geographical Influence


5. Academic Position


6. Additional Education


7. Research Experience


8. Publication Experience


9. Speaking Experience



Computes Total Score, assigns Tier (1–4), and determines Honorarium Rate using the OUS FMV rate table.


Stage 6: Export & Logging

Saves final datasets:

Updated FMV calculator (FMV_Calculator_Updated.xlsx)

Missing list (Missing_Doctors.csv)

Business-ready summary (DVL_updated.xlsx)


Maintains detailed logs (fmv_calculator.log) and error tracebacks.
